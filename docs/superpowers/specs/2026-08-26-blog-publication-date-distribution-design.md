# Равномерная хронология публикаций блога

## Цель

Создать правдоподобную историю регулярных публикаций для всех 40 статей блога: от августа 2021 года до августа 2026 года.

## Изменение данных

- Обновить только поле `publishDate` во frontmatter каждого файла `src/content/blog/*.md`.
- Упорядочить статьи хронологически с постоянным интервалом примерно 46–47 дней.
- Использовать даты внутри периода с 2021-08-26 по 2026-08-26 включительно.
- У последней статьи будет дата, близкая к текущей; у первой — дата около пяти лет назад.

## Границы

Не изменять slug, содержание, автора, категории, `updatedDate`, изображения, шаблоны страниц, JSON-LD и логику сортировки. Витрина блога продолжит сортировать статьи по обновлённому `publishDate`.

## Проверка

Проверить, что все 40 Markdown-файлов содержат корректную дату, даты уникальны, находятся в согласованном диапазоне и образуют строго возрастающую последовательность с приблизительно равными интервалами. Затем выполнить production-сборку Astro, чтобы Content Collection успешно распознала frontmatter.
