## Публикация

Результаты GitHub Actions, штатного деплоя и проверки публичного хоста дополняются после публикации. До их фиксации локальный результат не следует читать как подтверждение обновления production.

**Что сделано:** подтверждена работоспособность итоговой локальной сборки, SEO-контрактов и переходов по старым адресам.

**Что нужно от вас:** ничего для проверки и публикации нового сайта.

**Как увидеть результат:** открыть общий аудит и новый сайт после записи результатов публикации в этом протоколе.
