Проект: Сайт клиники экспертной медицины (маммология, гинекология, эндокринология, нутрициология) в Санкт-Петербурге. Astro 4 + React 18, claymorphism дизайн-система.

Ключевые находки: Сильная эмпатийная подача и уникальная визуальная система. Основные проблемы: контрастность цветов не проходит WCAG AA, утечка токенов в компонентах (14+ hardcoded цветов), конверсионная воронка "Второе мнение" спрятана глубоко на главной. Исправление критичных проблем доступности — ~4.5 часов, дизайн-токенов — ~6 часов.

3. UX-критика дизайна

B+

Usability

Вердикт

Сильная clay-дизайн-система создаёт теплый, нехолодный визуал — критично для медицинского контекста. Эмпатийная подача снижает тревожность. Однако информационная архитектура и CTA-размещение создают конверсионное трение: "Второе мнение" (главный лид-магнит) появляется поздно на главной, а кнопка "Записаться" повторяется 4+ раз на странице, вызывая баннерную слепоту.

Рекомендации Tier 1 (High Impact)

1. Переместить "Второе мнение" выше на главной

Сейчас: Hero → Услуги → Доктора → Отзывы → (поздно) Второе мнение.
Предложение: Hero → Второе мнение → Услуги → Доктора → Отзывы.
Ожидаемый эффект: +15-25% заявок на второе мнение.

2. Сократить количество CTA-кнопок

Оставить primary "Записаться" только в Header + sticky mobile. На страницах использовать btn-clay-secondary ("Подробнее"). Снижает баннерную слепоту.

3. Мобильная таблица ВАБ vs Операция

Заменить горизонтальный скролл на stacked-карточки для mobile. Ключевое сравнение должно быть читаемым на телефоне.

6. Research Synthesis (из proxy-данных)

Ключевые темы

Тема 1: Evidence-Based позиционирование

Источники: README "Последние изменения", hero-копирайт, SecondOpinion

Клиника прошла через "credibility reset": убраны неподтверждённые claims, переход к нейтральному языку. Пациенты ценят честность и понятный разговор больше, чем хайп.

Тема 2: Снижение тревожности как core value prop

Источники: Hero ("спокойным, понятным языком"), FAQ всех страниц, блог

Весь контент построен вокруг снятия страха. "Спокойно обсудим", "без давления". Статьи блога отвечают на тревожные вопросы. Нужно измерять "уверенность в решении" как KPI, не только записи.

Тема 3: "Второе мнение" как бизнес-логика

Источники: Hero слайд 2, SecondOpinion.jsx, ВАБ FAQ

Бесплатное второе мнение — gateway funnel: тревожный пациент с направлением → проверка документов → если ВАБ подходит → конверсия. Не cost center, а инструмент привлечения.

Тема 4: ВАБ как specialty moat + экосистема

Источники: SERVICES, pricing, Home слайд 3

Клиника владеет end-to-end маршрутом: консультация → ВАБ → гистология → follow-up (гинеколог/эндокринолог/нутрициолог). Ценообразование отражает это: базовая процедура + отдельные услуги.

Тема 5: Content-driven SEO — блог как demand gen

Источники: 17 блог-статей, blog metadata

Статьи адресуют конкретные pain points пациентов. Авторство привязано к врачам (E-E-A-T). Карусель "Врачи на ТВ" усиливает авторитет. Нужно отслеживать, какие статьи конвертируют в записи.

Тема 6: Прозрачное ценообразование

Источники: price-list.js, Vab.jsx, Home messaging

Переход от bundled "ВАБ под ключ" к itemized pricing (базовая + материалы + гистология). Dual-card design. Нужен калькулятор стоимости для self-screening перед записью.
