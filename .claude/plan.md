# Theme Switcher — всплывающее меню настройки темы

## Что делаем

Компонент `ThemeSwitcher.jsx` — плавающая кнопка (палитра) в углу экрана, по клику открывается панель с тремя секциями:

### 1. Цветовая тема (акцентный цвет)
Переключает `--accent`, `--accent-hover`, `--accent-light`, `--color-mint`, `--surface-mint`, `--surface-accent`, тени и градиенты.

Пресеты:
- **Emerald** (текущий): `#1B6B5A` — тёмно-зелёный
- **Ocean**: `#2563EB` — синий
- **Berry**: `#7C3AED` — фиолетовый
- **Coral**: `#DC2626` — красно-коралловый
- **Amber**: `#D97706` — янтарный

Каждый пресет — набор из ~12 CSS-переменных, которые перезаписываются на `:root`.

### 2. Шрифт заголовков (hero, heading-display, heading-serif)
Переключает `--font-serif` и подгружает шрифт при необходимости.

Варианты:
- **Cormorant Garamond** (текущий) — элегантная антиква
- **Playfair Display** — классическая serif
- **Lora** — тёплая serif
- **Montserrat** — геометрический sans
- **Raleway** — тонкий sans

### 3. Шрифт основного текста (body)
Переключает `font-family` на `body` и в Tailwind `sans`.

Варианты:
- **Golos Text** (текущий) — кириллический гротеск
- **Inter** — популярный UI-шрифт
- **Nunito** — скруглённый, дружелюбный
- **Source Sans 3** — Adobe, нейтральный
- **PT Sans** — классический кириллический

## Файлы

| Файл | Действие |
|------|----------|
| `src/components/ThemeSwitcher.jsx` | **Новый** — компонент переключателя |
| `src/components/pages/Home.jsx` | Добавить `<ThemeSwitcher />` |
| `src/styles/global.css` | Добавить CSS для панели (минимально, всё через CSS vars) |

## Техника

- Все настройки применяются через `document.documentElement.style.setProperty()` — мгновенное переключение без перезагрузки
- Google Fonts подгружаются динамически через `<link>` при выборе нового шрифта
- Выбранная тема сохраняется в `localStorage` и применяется при загрузке
- Панель закрывается по клику вне неё
- Кнопка — иконка палитры (Lucide `Palette`), фиксированная в правом нижнем углу
