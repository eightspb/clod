# Перенос адресов Tilda на новый сайт

Дата сверки: 8 сентября 2026 года. Старый сайт пока работает на `odintsovclinic.ru`; новый — на `new.odintsovclinic.ru` с запретом индексации. DNS и настройки Tilda в этой задаче не менялись.

## Объём и источники

Проверены [robots.txt](https://odintsovclinic.ru/robots.txt), [основной sitemap Tilda](https://odintsovclinic.ru/sitemap.xml) и [sitemap магазина](https://odintsovclinic.ru/sitemap-store.xml). В них 58 URL: 55 страниц и три тестовых товара. Для страниц зафиксированы HTTP-статус, title, H1, существующий маршрут/редирект и рекомендация в [полной таблице CSV](migration-urls-2026-09-08.csv).

Карта составлена по публичным sitemap и содержимому. Она не включает все исторические URL из серверных логов, Вебмастера, Search Console и внешних ссылок, поскольку этих выгрузок пока нет. Перед переносом дополнить таблицу такими адресами, особенно получавшими переходы и ссылки.

После текущих исправлений 17 старых URL имеют одноимённую страницу, 19 — подходящий настроенный редирект. Ещё 18 требуют подтверждения услуг/врачей или содержания, один общий раздел УЗИ — уточнения назначения, три тестовых товара — удаления из опубликованного каталога. Состояние CSV описывает конфигурацию нового сайта, а не утверждает, что DNS-перенос уже состоялся.

Добавлены четыре новых правила, исправлены три прежних назначения. `e2e/seo-migration.spec.js` проверяет для каждого HTTP 301, точный `Location` и HTTP 200 цели без следующего редиректа. Старый основной домен продолжает возвращать Tilda до будущего переноса.

## Решения до переноса

| Группа | Что обнаружено | Как завершить |
|---|---|---|
| Общая ультразвуковая диагностика `/usd` | Старый раздел шире маммологии, куда он сейчас перенаправляется | Подтвердить актуальный набор УЗИ; ближайшая существующая информация — `/prices/full#ultrasound`, полноценный раздел услуги полезнее при достаточном содержании |
| `/procedures`, `/lab` | Старые разделы обещали более широкий набор процедур/анализов, чем явно подтверждено на новом сайте | Сверить прайс и доступность, затем выбрать соответствующую страницу или восстановить подтверждённую услугу |
| `/urology`, `/neurology` | В старом sitemap есть направления, в текущих девяти профилях нет соответствующих врачей; при этом некоторые позиции сохранились в полном прайсе | Подтвердить приём и актуализировать одновременно направление, врача и прайс |
| `/doctors/busko`, `/doctors/lipina`, `/doctors/ignateva`, `/doctors/yakhontova`, `/doctors/strebkov`, `/doctors/ovchinnicova` | Старые именные профили отсутствуют в текущей команде; часть направлена на общий список | Если сотрудничество продолжается — восстановить достоверный профиль; если завершено — корректная страница отсутствия/архив по реальному статусу. Не изображать запись к отсутствующему врачу |
| Проктологические и урологические `/exams/*` | Несколько старых услуг направляются на главную; содержание кишечной полипэктомии нельзя заменить гинекологической процедурой | Восстановить действующую услугу либо убрать нерелевантный редирект и вернуть 404/410 при окончательном снятии |
| `/job`, `/otzyv`, `/action` | Вакансии, отзывы и акции имеют собственный интент, которого может не быть на общей целевой странице | Подтвердить актуальное содержание/права на перенос; законченные акции не выдавать за действующие |
| Три `/tproduct/*`: Apples, Pears, Bananas | Публичные тестовые товары Tilda, не относящиеся к клинике | Удалить из магазина и sitemap Tilda. На новом сайте отсутствуют; 404 допустим, 410 можно использовать для явно окончательного удаления |

Для страниц без подходящей замены корректный 404/410 предпочтительнее массового перенаправления на главную. Для сохранившегося содержания использовать прямой постоянный переход к наиболее близкой странице. Это соответствует [рекомендациям Google по переносу URL](https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes).

Обнаруженные спорные правила не удалены автоматически: без знания фактической доступности услуг нельзя объявить медицинское направление закрытым. Они перечислены как условия готовности к переносу; нынешний Tilda-сайт эта поставка не меняет.

## Порядок запуска на основном домене

1. Дополнить CSV историческими URL, входящими ссылками и посадочными страницами из аналитики; закончить решения из таблицы выше.
2. Сохранить резервные копии сайта, базы, медиа и настроек DNS; проверить доступность отката по инструкции проекта.
3. Подготовить сертификат и конфигурацию основного домена, сохранив точные URL. Основной адрес в сборке уже `https://odintsovclinic.ru`.
4. В согласованное окно направить основной домен на новый сайт. Снять `NOINDEX` только в конфигурации основного публичного сайта; поддомен затем закрыть либо перенаправить по утверждённой схеме.
5. Проверить HTTP и meta robots, canonical, sitemap, HTTPS, WWW, изображения по абсолютным URL и отсутствие цепочек редиректов. На основном домене каждая из 76 нужных страниц должна открываться с HTTP 200; 404 должен оставаться 404.
6. Выполнить `bun run audit:seo --base-url https://odintsovclinic.ru --live --output /tmp/clod-seo-cutover.json` и проверить все старые адреса из CSV.
7. Обновить sitemap в Вебмастере/Search Console, проверить важные URL инструментами кабинетов; обновить сайт/услуги в управляемых внешних карточках.
8. Отслеживать ошибки обхода, выбранные canonical, старые URL в выдаче и записи пациентов. Сохранять редиректы длительно; не удалять их сразу после первого успешного обхода.

Перенос платформы при сохранении основного домена не является сменой доменного имени. Инструменты смены адреса в поисковых кабинетах применять только если фактически меняется домен; отправка sitemap и контроль URL нужны в любом случае.
