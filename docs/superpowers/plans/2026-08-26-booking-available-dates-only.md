# Календарь только со свободными датами — план реализации

> **Для агента-исполнителя:** использовать TDD и выполнять шаги последовательно. По просьбе пользователя план не содержит фрагментов кода; код пишет исполнитель после получения задания.

**Цель:** убрать из онлайн-записи даты без свободных интервалов, сохранив выбор даты и времени.

**Архитектура:** изменить только представление расписания. API и нормализация ответа Medflex остаются без изменений; компонент строит полосу дат непосредственно из доступных дат расписания.

**Стек:** Astro 4, React 18, Vitest, Testing Library.
