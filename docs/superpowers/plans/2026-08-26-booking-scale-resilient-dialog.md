# Масштабоустойчивое окно онлайн-записи — план реализации

> **Для агента-исполнителя:** использовать TDD и выполнять шаги последовательно. План не содержит фрагментов кода согласно правилам проекта; код пишет исполнитель после подтверждённого падения теста.

**Цель:** сохранить все тексты онлайн-записи читаемыми и удерживать действия внутри диалога при каждом встроенном размере текста от 65% до 135% и на мобильных и настольных окнах.

**Архитектура:** разделить диалог на неподвижную шапку, единую прокручиваемую область и отдельный нижний узел действий. Существующие компоненты шагов сохраняют владение своими кнопками, но выводят нижние панели через единый portal-компонент в узел действий. Прокручиваемая область остаётся одноколоночной на mobile и двухколоночной на desktop.

**Стек:** Astro 4, React 18, React DOM portal, Tailwind CSS 3, Vitest, Testing Library, Playwright.
