# GEO baseline Клиники Одинцова в генеративном поиске Яндекса

Дата измерения: 8 сентября 2026 года.

## Что измерялось

Проверена видимость бренда в пяти нейтральных вопросах выбора клиники в Санкт-Петербурге: маммология, ВАБ, гинекология, эндокринология и нутрициология. Вопросы не содержали название Клиники Одинцова и не ограничивали поиск её доменом.

Использован официальный [генеративный Yandex Search API](https://aistudio.yandex.ru/ru/docs/search-api/operations/generative-search), endpoint `/v2/gen/search`, полный структурированный ответ без промежуточных результатов. Поля `site`, `host` и `url` не передавались, поэтому сервис искал по всему индексу Яндекса. Согласно [описанию режима](https://aistudio.yandex.ru/ru/docs/search-api/concepts/generative-response), модель формирует ответ на основе результатов поиска и возвращает использованные источники.

Это технический API baseline, а не проверка пользовательской Алисы, Нейро или обычной страницы поиска Яндекса. У Gen Search API нет отдельного регионального параметра в использованной схеме; Санкт-Петербург задавался прямо в каждом вопросе.

Медицинские советы и утверждения из сгенерированных ответов здесь не публикуются. Зафиксированы только видимость бренда, цитируемые страницы, источники и названные альтернативы.

1. В текущем состоянии бренд не попал ни в один из пяти генеративных ответов и ни в один список использованных источников.
2. Для запросов выбора специалиста генератор опирается на агрегаторы, карты и крупные клиники с отдельными страницами направления.

## Стоимость и ограничения

Выполнено 5 попыток и получено 5 успешных ответов; повторов и ошибок не было. По официальному [тарифу Yandex Search API](https://aistudio.yandex.ru/ru/docs/search-api/pricing) 5,08 ₽ за генеративный запрос стоимость baseline составляет **25,40 ₽**.

Предыдущее исследование Wordstat и обычной выдачи имеет отдельную консервативную оценку 15,58 ₽. Общая консервативная оценка двух исследований: **40,98 ₽**. Оценка успешных платных запросов без неуспешных HTTP 400 предыдущего исследования: **34,05 ₽**. Это расчёт по опубликованному тарифу, а не сумма из счёта биллинга.

Общий технический журнал с учётом предыдущего исследования и отдельной нетарифицируемой проверки HTTP 401: 131 HTTP-вызов, 111 успешных и 20 неуспешных.

Ограничения baseline:

- пять ответов — минимальный срез, а не статистически устойчивое исследование;
- Gen Search API отличается от пользовательских продуктов Яндекса;
- город задан текстом вопроса, отдельной фиксации региона в запросе нет;
- генеративный ответ и набор источников могут измениться при повторе того же вопроса;
- отсутствие упоминания не доказывает отсутствие бренда во всех возможных формулировках;
- содержание ответа не проверялось как медицинская рекомендация и не должно использоваться для лечения или выбора медицинской тактики.
