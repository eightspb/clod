# Поэтапное исправление замечаний SEO/GEO

Продолжение аудитов от 8 сентября 2026 года. Начальная версия — `5cfcb0d`; технические исправления первого аудита уже опубликованы в `1ed976d`.

## Этапы и границы

| Этап | Исправления | Приёмка |
|---|---|---|
| 1. Достоверные данные и ссылки | Единые внешние карточки в видимом контенте и JSON-LD; 150+ обученных врачей; реальные значения счётчиков в серверном HTML | Компонентные тесты и HTML без JavaScript |
| 2. Мобильная загрузка и доступность | Responsive-портреты, контраст небольшого текста и кнопок, последовательность заголовков, имена ссылок | Unit, браузер на полной странице, Lighthouse |
| 3. Подготовка миграции | Релевантная цель общего УЗИ, устранение переходов несвязанных услуг на главную, проверка индексации основного домена | Unit, HTTP/E2E, live-аудит |
| 4. Поставка | Общие тесты, lint, build, CI, штатный деплой с бэкапом | Smoke, live-обход и целевые браузерные проверки |

Этапы 1–3 выполняются параллельно по отдельным файлам. DNS, индексация staging и внешние карточки не меняются. Медицинские назначения и рецензирование не создаются в рамках технической правки.

## Подтверждение владельца

8 сентября владелец подтвердил использование опубликованных цифр и попросил заменить число обученных врачей на «больше 150». Распределение процедур по годам сохранено до получения более точных данных. География, показатели процедур и рейтинги остаются по указанию владельца. На публичном сайте не добавляются подписи о неподтверждённых данных. Это подтверждение владельца, а не независимая проверка исходного реестра.

## Оставшиеся внешние этапы

- Доступы к Яндекс Вебмастеру, Search Console и Метрике для фактических показов, индексации и конверсий; доступ владельца к карточкам организации.
- Подтверждение состава старых услуг и статуса отсутствующих врачей для окончательной карты переноса. Отсутствие релевантного нового URL само по себе не означает закрытие услуги.
- Медицинское рецензирование страниц и статей уполномоченным врачом; точные данные распределения ВАБ по годам от владельца.
- Отдельно согласованное окно переноса основного домена. Повторная GEO-панель после переноса и обхода поисковыми системами.

Точные протоколы независимых участков: [портреты](portrait-fix-2026-09-08.md), [доступность](accessibility-fix-2026-09-08.md), [миграция](migration-fix-2026-09-08.md).

- Общие unit: 2 392 теста; ESLint и production-сборка — exit 0.
- Целевой браузерный прогон: 105 сценариев прошли, один существующий сценарий Pagefind пропущен локально, поскольку он требует CI production-сервера; он остаётся в полном CI.
- Аудит сборки + SSR: 76 URL, ноль ошибок и предупреждений. `indexabilityChecked: false` для локальной проверки.
- Мобильный viewport 390×844, полная главная при `scrollY = 0`: прозрачные края, геометрия слоёв и две строки имени сохранены; браузер реально выбирает уменьшенные WebP.
- Lighthouse 13.4.1: исходная live-главная — Accessibility 95/100, локальная production-сборка — 100/100, неуспешных accessibility-аудитов нет. Это автоматическая проверка в конкретном режиме, не полная сертификация доступности.
- Независимое ревью подтвердило корректность `srcset/sizes` и обнаружило два граничных случая robots.txt; исправлены специфичность правил с `$`/`*` и варианты `Googlebot*`/`Googlebot/1.2`. Итоговый набор аудитора — 34 теста, включая Red → Green для замечаний ревью.
