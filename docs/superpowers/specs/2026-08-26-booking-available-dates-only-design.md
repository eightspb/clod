# Календарь только со свободными датами

## Контекст

Medflex возвращает расписание отдельными датами со свободными слотами. Текущий интерфейс дополняет ответ всеми календарными днями четырнадцатидневного окна и показывает дни без слотов как неактивные карточки. Из-за этого ближайшая доступная дата может оказаться за пределами видимой области.

## Решение

Полоса дат показывает только даты, полученные в доступном расписании. Порядок остаётся хронологическим и соответствует нормализованному ответу расписания. Первая доступная дата по-прежнему выбирается автоматически, а при выборе другой даты отображаются только её интервалы времени.

Пустые дни не получают кнопок, подписей или скрытых интерактивных элементов. Серверный контракт и четырнадцатидневное окно загрузки не меняются.

## Пограничные состояния

- Если свободных дат нет, существующий экран «Нет свободного времени» остаётся без изменений.
- Если доступные даты разделены несколькими календарными днями, рядом отображаются только доступные даты без заполнителей между ними.
- Доступные названия кнопок сохраняют дату, день недели и количество свободных интервалов.

## Проверка

Компонентный регрессионный тест использует разреженное расписание и подтверждает, что в полосе есть только доступные даты, выбранная дата корректна и смена даты продолжает переключать группы времени.
